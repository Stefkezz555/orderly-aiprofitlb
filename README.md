# Orderly

Interni dashboard porudžbina za više prodavnica.

## Pokretanje lokalno

Potrebni su Node.js LTS i npm.

```powershell
npm install
npm run dev
```

Otvori [http://localhost:3000](http://localhost:3000).

## Tehnologije

- Next.js 16 App Router
- TypeScript i ESLint
- Tailwind CSS v4
- React

Projektna pravila i plan implementacije nalaze se u [CLAUDE.md](./CLAUDE.md). Pre rada na Next.js kodu pročitaj odgovarajuću dokumentaciju u `node_modules/next/dist/docs/`.
